# Superpowers-style Spec — V0.2

## Problem

上一版演示应用需要访问 `/example-app/`，且“单词学习”只是平铺词卡，不够像真正的每日学习产品。

## Goal

把项目整理为根目录可直接运行的 Vite + React + TypeScript 网站，并让“今日单词”成为第一主流程。

## Required behaviors

- 根地址直接打开网站；
- 首页显示“今日学习单词”；
- 每日学习单词数量可由用户自定义；
- 同一天的今日单词保持稳定；
- 单词可免费朗读；
- 学过的词进入统一复习；
- 复习可切换 英→中 / 中→英；
- 继续保留句子训练和阅读入口；
- 全部进度默认只存在浏览器。

## Non-goals / YAGNI

本轮不做账号、云同步、Postgres、Redis、付费 AI、社区、排行榜、大型课程树。

## Acceptance criteria

1. `npm run dev` 后访问 `/` 就进入 React 应用；
2. 每日词数允许 1 到词库上限；
3. 每日选词对同一日期稳定；
4. 学过的单词能在复习页出现；
5. 复习方向可以切换；
6. 刷新后设置与进度仍存在；
7. 单词调度核心逻辑有测试；
8. `npm run build` 可产生 `dist/`（在有 npm 依赖的环境中）。
