# Superpowers Workflow Reference

参考 obra/superpowers 的开发方法，将本项目流程约束为：

```text
clarify / spec
→ implementation plan
→ test-first for learning rules
→ implement smallest useful slice
→ refactor
→ verify
→ review scope
```

本轮 V0.2 的重点不是增加功能数量，而是让“今日单词 + 自定义词数 + 双向复习”形成可靠的免费学习闭环。
