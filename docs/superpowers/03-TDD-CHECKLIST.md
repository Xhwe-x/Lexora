# TDD Checklist

每加一个学习规则，都按 RED → GREEN → REFACTOR：

- [ ] 先写一个只描述单一行为的测试；
- [ ] 确认失败来自功能尚未实现；
- [ ] 写最小实现；
- [ ] 跑相关测试；
- [ ] 再整理命名与复用；
- [ ] React 组件只消费核心函数；
- [ ] 不把每日计划/SRS 规则散落进 UI；
- [ ] 新增依赖前先判断浏览器原生能力是否够用；
- [ ] 新增数据库前先证明 localStorage/IndexedDB 不够；
- [ ] 新增 AI 前确保无 AI 主流程仍完整可用。
