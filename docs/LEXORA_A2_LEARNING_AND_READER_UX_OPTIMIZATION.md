# Lexora A2 学习入口、练习反馈与 Reader 优化规范

> 版本：Draft v2.0
> 基准水平：A2
> 目标：把 Lexora 从“先测评再进入网站”的原型，调整为“先进入产品、第一次正式学习时完成起点测评”，并优化语境题、中文释义、键盘操作和阅读体验。
> 性质：产品、交互和内容模型规范；本文件先于代码实现。

## 1. 本轮必须修正的体验问题

### 1.1 测评不应该阻塞网站入口

当前行为是：没有 placement profile 时，App 直接渲染 PlacementOnboarding，用户无法先浏览网站。

目标行为：

~~~text
第一次打开网站
  ↓
先进入 Lexora 首页
  ↓
可以浏览今日、单词、阅读、复习、我的
  ↓
第一次点击“开始今日学习”
  ↓
在学习 Session 内出现“A2 起点测评”
  ↓
测评完成后立即进入第一组正式学习
~~~

测评仍然是首次正式学习的必要步骤，但不再是网站入口的门禁。

### 1.2 语境理解题需要重新排版

当前语境题的问题不是功能缺失，而是信息层级不够清楚：题干、句子、选项和辅助信息容易挤在同一层。

新的优先级必须是：

1. 用户现在要完成什么；
2. 句子中的空缺在哪里；
3. 用户要从哪些答案中选择；
4. 选择后如何确认与继续。

不要把词义、等级、分类、完整解释和过多装饰同时放在题目中央。

### 1.3 “确定答案”必须支持 Enter

所有存在输入框的练习都必须支持：

- 输入答案后按 Enter，相当于点击“确定答案”；
- 答案已经提交后按 Enter，相当于点击“继续”；
- 选择题选中选项后按 Enter，可以确认；
- 不能因为 Enter 事件冒泡导致重复提交；
- 提交后焦点要转移到“继续”或下一题的第一个输入控件。

按钮仍然保留，因为触屏用户和鼠标用户不应被迫使用键盘。

### 1.4 中文信息需要更完整，但不能泄露答案

当前词条的中文释义较短，容易让用户只记住一个对应关系。A2 练习应提供更多中文线索，包括：

- 核心释义；
- 常见的第二义项；
- 词性；
- 常见使用场景；
- 与当前题目相关的中文语境；
- 必要时给出搭配说明。

扩充中文信息的目的，是帮助用户理解词的使用范围，而不是把正确英文直接写在题目里。

### 1.5 Reader 需要从“单篇文本工具”变成“阅读学习入口”

当前 Reader 已经具备点击查词、显示当前语境、发音、加入词库、粘贴文本和保存阅读进度等基础能力，但仍然是一个单文档工具。

后续应逐步增加：

- A2/B1 内容分层；
- 日常、工作、旅行、考试等主题；
- 推荐文章；
- 音频与文本同步；
- 文章阅读前准备；
- 阅读中的词和短语收藏；
- 阅读结束后的理解练习和复习包。

## 2. 目标用户与默认策略

本轮以 A2 用户作为默认设计对象，同时保留两条学习方向：

- **日常英语**：真实交流、生活、工作、旅行；
- **考试英语**：通用考试词汇、阅读、听写、长难句和书面表达。

用户可以在进入网站后先查看产品，但第一次点击正式学习时仍要完成起点测评。

如果用户选择“两者都要”，初始推荐为：

~~~text
日常英语 60% + 考试英语 40%
~~~

这个比例只作用于新学习内容；到期复习和最近错误仍然优先处理。

## 3. 新的首次学习流程

### 3.1 首页状态

没有测评画像时，首页仍然可以渲染，但要显示未完成状态：

~~~text
欢迎来到 Lexora
完成第一次学习时，我们会用一组短测帮你找到合适的起点。

今日学习
开始第一次学习
~~~

不要在首页显示伪造的 A2 分数、日常/考试比例或薄弱能力。

有有效画像时，首页显示：

~~~text
当前起点：A2
主路径：日常英语
今日建议：日常 60% · 考试 40%
~~~

### 3.2 第一次点击“开始今日学习”

App 不再使用“没有画像就渲染整页测评”的全局拦截。

改为：

1. 用户点击“开始今日学习”；
2. 如果没有有效 placement profile，进入 Session 内的 Placement 阶段；
3. 如果已有有效画像，直接进入 daily Session；
4. 测评完成后保存画像；
5. 继续用户刚才发起的“开始今日学习”动作；
6. 不清除已有 progress、settings、review、learning history 或 Reader 数据。

如果已有旧版本地学习数据但没有 placement profile，文案应说明：

~~~text
这是一次新的学习起点测评。
你之前的学习记录会保留，测评只用于安排之后的内容。
~~~

### 3.3 测评的容器

Placement 不应再像独立欢迎页一样把用户挡在网站外面，而应该复用学习 Session 的空间结构：

- 顶部：退出、进度和“起点测评”标签；
- 中间：一道题；
- 底部：确认、下一题和键盘提示；
- 完成后：简短结果卡；
- 结果卡之后：自动进入第一组正式学习。

可以保留独立的视觉卡片，但行为上必须属于“第一次学习”。

## 4. 语境理解题的新布局

### 4.1 推荐结构

~~~text
┌──────────────────────────────────────┐
│ 语境理解                              │
│ 选择最适合当前句子的表达               │
│                                      │
│  I want to ______ my English.        │
│                                      │
│  这句话表达的是：希望让英语变得更好。  │
│                                      │
│  A  improve       B  invite          │
│  C  explain      D  repeat           │
│                                      │
│  [确认答案 Enter]                     │
└──────────────────────────────────────┘
~~~

视觉层级：

1. 小号题型标签：语境理解；
2. 简短指令：选择最适合当前句子的表达；
3. 大号句子卡：空缺必须醒目；
4. 可选中文提示：只解释语境，不显示英文答案；
5. 选项卡片：两列桌面端、一列移动端；
6. 确认按钮：显示 Enter 键提示。

### 4.2 选项交互

- 点击选项后只表示“已选择”，不要立刻跳题；
- 选中的选项有清晰边框、背景和按下状态；
- 点击“确认答案”后锁定选项；
- 正确：展示完整句子、中文解释和下一步；
- 错误：显示用户选项、正确选项、错误原因和稍后重练；
- 确认后 Enter 进入下一步；
- 移动端不依赖悬停状态。

### 4.3 题干不要承担所有信息

以下内容不应全部堆在语境题中央：

- A1/A2/B1 等级；
- 日常/考试轨道；
- 词性；
- 多个中文义项；
- 完整词典解释；
- 例句翻译；
- 统计信息。

等级和轨道可以放在题卡顶部的弱提示区域；详细词义只在提交后的反馈区展开。

## 5. Enter 键与焦点规范

### 5.1 输入题

输入框处于激活状态时：

~~~text
有内容 + 未提交 + Enter → 提交答案
无内容 + Enter → 不提交
已提交 + Enter → 继续
~~~

提交函数必须是幂等的。可以通过当前反馈状态、当前题目 ID 或禁用状态防止重复提交。

### 5.2 选择题

~~~text
未选择 + Enter → 不提交
已选择 + Enter → 确认答案
已确认 + Enter → 继续
~~~

数字键 1～4 可以作为后续增强，但不是本轮必需项。

### 5.3 焦点移动

- 进入输入题时，桌面端自动聚焦输入框；
- 移动端不要强制弹出键盘；
- 提交后焦点移动到“继续”；
- 点击“继续”进入下一题后，焦点移动到新题的第一个可操作控件；
- 打开移动端词卡后，焦点进入词卡；
- 关闭词卡后，焦点返回触发该词的按钮；
- 弹窗和底部抽屉支持 Escape 关闭。

## 6. 中文释义与内容模型

### 6.1 Word 模型建议

当前 Word 只有一个 zh 字符串，不足以承载 A2 学习所需的多义项和使用提示。

建议逐步扩展为：

~~~ts
type WordMeaning = {
  text: string
  partOfSpeech?: string
  usageNote?: string
}

type Word = {
  id: string
  en: string
  zh: string
  meanings?: WordMeaning[]
  collocations?: string[]
  example: string
  exampleZh: string
  level: 'A1' | 'A2' | 'B1'
  category: '日常' | '学习' | '交流' | '动作' | '描述'
  track?: 'daily' | 'exam' | 'shared'
}
~~~

旧数据仍然以 zh 作为主释义，新增字段全部可选，保证历史词条兼容。

### 6.2 单词卡展示

单词卡默认显示：

~~~text
improve
提高；改善
动词

常见用法：improve + 名词
Reading can improve your vocabulary.
阅读可以提高你的词汇量。
~~~

点击“更多释义”后再显示：

~~~text
1. 提高；改善
2. 改进表现
3. 改善健康或状态
~~~

避免首次展示就像完整词典一样拥挤。

### 6.3 中文 → 英文题

中文题干应从“一个中文词”升级为“有足够语境的中文任务”：

~~~text
请写出英文：

阅读可以提高你的词汇量。
这里表达的是“让某种能力变得更好”。
目标词性：动词
~~~

对于多义词，应优先使用当前句子的目标义项，并在提交后解释其他常见义项：

~~~text
change
改变；变化
也可以表示“零钱”或“更换”。
本题使用的是“改变”的动词用法。
~~~

中文提示不能直接出现英文首字母或完整答案，除非用户主动请求提示。

### 6.4 内容编辑原则

每个 A2 词至少准备：

- 1 个核心义项；
- 1 个常见扩展义项或搭配；
- 1 个日常语境例句；
- 1 个考试/书面语境例句（适用时）；
- 1 个简洁的中文解释。

这会让同一个词能够服务两条路径，而不需要维护两套重复词库。

## 7. Reader 专业化优化方向

本节结合成熟英语学习网站的公开交付方式：

- British Council 按等级、文本类型和阅读技能组织内容，并采用“准备 → 阅读 → 练习”的流程。[Reading](https://learnenglish.britishcouncil.org/free-resources/reading)
- Readlang 把点击查词、即时翻译和后续闪卡练习连成一个闭环。[Readlang](https://readlang.com/)
- LingQ 将内容库、用户导入、已知词/学习词标记、音频文本和间隔复习结合起来。[LingQ](https://www.lingq.com/en/learn-english-online/)
- BBC Learning English 的课程常见“音频/视频 → 文本 → 词汇回顾 → 小测”结构。[BBC Learning English](https://feeds.bbci.co.uk/learningenglish)
- 句乐部将阅读、点词查义、单句朗读、听写和口语练习组织在同一内容体系中。[句乐部帮助文档](https://julebu.co/docs/)

### 7.1 Reader 首页

Reader 不应只有“我的阅读”这一篇文本，建议改为：

~~~text
我的阅读

继续阅读
The Small Habit
A2 · 日常 · 还剩 6 分钟

推荐给你
┌────────────┐ ┌────────────┐
│ A2 日常对话 │ │ A2 工作邮件 │
│ 8 分钟      │ │ 10 分钟     │
└────────────┘ └────────────┘

筛选：A2 · 日常 · 5-10 分钟
~~~

筛选维度：

- 难度：A1、A2、B1；
- 方向：日常、考试、共享；
- 主题：生活、工作、旅行、学习、观点；
- 时长：5 分钟内、5～10 分钟、10 分钟以上；
- 类型：短文、对话、邮件、故事、新闻、音频文本。

### 7.2 文章开始前

文章详情页先给用户一个低压力预览：

~~~text
介绍自己与表达观点
A2 · 日常英语 · 约 8 分钟

你将练习：
表达观点、同意和不同意

预计遇到：
4 个新词 · 2 个重点表达

[开始阅读]
~~~

不要在阅读前显示一整页词表，避免把阅读变成预习考试。

### 7.3 Reading Canvas

桌面端：

- 左侧或主区域显示正文；
- 右侧固定 Word Inspector；
- 顶部显示文章标题、难度、进度和播放控制；
- 点击单词或短语后，右侧展示释义、当前语境、发音和保存操作。

移动端：

- 正文保持足够宽的阅读区域；
- 点击词语后打开底部词卡；
- 词卡可向下拖动关闭，也可以用关闭按钮；
- 词卡内部支持滚动；
- 不要用小型悬浮气泡遮住正文。

正文单词状态：

- 未查询：普通文本；
- 已查询：轻微背景提示；
- 已加入学习：细下划线；
- 已掌握：弱化标记；
- 当前选中：明显但不刺眼的背景。

### 7.4 阅读中的词卡

词卡信息顺序：

~~~text
interesting
A1 · 形容词

有趣的；引起兴趣的

当前语境
Read something interesting.
阅读一些有趣的内容。

[播放发音] [加入学习]

更多
常见搭配：interesting idea / interesting story
~~~

如果本地词库没有收录：

~~~text
暂时没有完整词条
你仍然可以继续阅读或播放发音。
~~~

不能假装所有词都有准确词典解释。

### 7.5 阅读播放

Reader 后续应支持：

- 播放全文；
- 播放当前句；
- 播放/暂停；
- 0.8x、1.0x、1.2x 速度；
- 当前句高亮；
- 跟随播放自动滚动；
- 关闭自动滚动；
- 减少动态效果时关闭高亮动画。

第一阶段可以先做“播放当前句”，再扩展到全文同步。

### 7.6 阅读结束后

读完文章不要只停在 100%：

~~~text
阅读完成

你读完了 A2 · 日常英语 · 介绍自己与表达观点

新遇到 5 个词
已保存 2 个词
阅读用时 8 分钟

[复习本文词汇] [继续读下一篇]
~~~

复习包可以包含：

- 2～3 道文章理解题；
- 2 个关键词选择题；
- 1 道句子填空；
- 1 道中文 → 英文主动回忆；
- 文章中保存的短语。

### 7.7 自定义文本

保留当前“粘贴 / 编辑文本”的快速入口，但把它放在内容库末尾：

~~~text
找不到想读的内容？
[粘贴自己的英文]
~~~

自定义文本第一阶段只需要保存：

- 标题；
- 正文；
- 阅读进度；
- 阅读设置；
- 查过的词；
- 保存的词。

多文章库、URL 导入、视频字幕导入和跨设备同步属于后续阶段，不应在本轮假装已经支持。

## 8. Reader 数据模型建议

当前 Reader 是单文档模型，后续可以逐步演进：

~~~ts
type ReaderContent = {
  id: string
  title: string
  text: string
  level: 'A1' | 'A2' | 'B1'
  track: 'daily' | 'exam' | 'shared'
  topic: string
  kind: 'article' | 'dialogue' | 'email' | 'story' | 'audio-transcript'
  estimatedMinutes: number
  audioUrl?: string
  source?: 'built-in' | 'custom'
}

type ReaderSentence = {
  id: string
  contentId: string
  text: string
  translation?: string
  startTimeMs?: number
  endTimeMs?: number
}

type ReaderSavedPhrase = {
  id: string
  contentId: string
  sentenceId?: string
  text: string
  translation?: string
  savedAt: string
}
~~~

现有 reader-document 和 reader-interactions 应继续兼容，迁移时不要丢失当前文章和查词记录。

## 9. 代码实施顺序

### P0：先修正入口和练习体验

1. 移除 App 对 Placement 的全局阻塞；
2. 首页支持无画像状态；
3. 第一次点击开始学习时进入 Placement；
4. 测评完成后继续原来的学习动作；
5. 语境题改成“题型 → 句子 → 选项 → 确认”的布局；
6. 为输入题和选择题统一接入 Enter；
7. 管理提交后的焦点；
8. 扩充当前 A2 词条的中文释义和搭配。

### P1：Reader 内容和文章体验

1. Reader 首页增加继续阅读和推荐内容；
2. 为内置文章增加等级、方向、主题和时长；
3. 优化桌面 Word Inspector 和移动端底部词卡；
4. 增加当前句播放；
5. 增加阅读完成总结；
6. 保存短语和文章理解结果。

### P2：句子学习核心

1. 新增独立的 Sentence 模型；
2. 句子排序；
3. 句子中译英；
4. 听写；
5. 句型和搭配错误反馈；
6. 句子级间隔复习。

### P3：内容生态与口语

1. 多文章内容库；
2. 用户导入文章；
3. 音频和字幕同步；
4. 跟读和录音；
5. 场景角色对话；
6. 具体考试路线。

## 10. 验收标准

### 首次学习

- 打开网站后可以先看到首页；
- 可以在未测评时浏览其他页面；
- 第一次点击“开始今日学习”进入测评；
- 测评完成后自动进入正式学习；
- 已有本地学习记录不会被清除；
- 刷新后不重复测评，除非画像无效或用户主动重测。

### 练习交互

- 语境题句子和空缺清楚；
- 选项在桌面端和移动端都不拥挤；
- 输入题按 Enter 可以提交；
- 选择题确认后按 Enter 可以继续；
- 不会出现重复提交；
- 提交后焦点位置可预测；
- 错误反馈包含用户答案、正确答案和下一步。

### 中文内容

- A2 词条至少有核心释义、词性和例句；
- 多义词能够解释当前题目使用的义项；
- 中文提示不直接泄露完整英文答案；
- 日常和考试语境可以复用同一个词条。

### Reader

- 可以从 Reader 首页继续当前文章；
- 文章能够显示难度、方向、主题和预计时长；
- 点击单词能看到当前语境；
- 词卡可以播放、加入学习和关闭；
- 移动端词卡不会遮挡或破坏正文阅读；
- 阅读进度和查词记录仍然保存；
- 第一阶段不承诺尚未实现的 URL、视频或跨设备导入。

## 11. 仍需确认的产品问题

本轮建议先按 A2 + “通用考试英语”实现，避免同时维护四六级、考研和雅思三套内容体系。

在开始代码改造前，需要确定一个方向：

> **Reader 第一批内置内容，你更希望优先提供日常生活/工作短文，还是优先提供四六级风格的考试阅读？**

这个选择会决定第一批文章的词汇、句子长度、题型和首页推荐排序。
